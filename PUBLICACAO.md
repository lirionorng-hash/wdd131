# Publicação correta no GitHub Pages

1. Abra esta pasta `wdd131_publicacao` no seu computador.
2. Envie para a **raiz** do repositório `wdd131` o arquivo `index.html`, `README.md`, `AUDITORIA.md`, `PUBLICACAO.md` e as pastas completas `estilos`, `scripts`, `imagens`.
3. **Não** envie a pasta `wdd131_publicacao` como uma subpasta. No GitHub, `index.html` deve aparecer imediatamente na raiz.
4. Se a interface web do GitHub não preservar as pastas no upload, use Git pelo VS Code (recomendado): copie os arquivos da pasta `wdd131_publicacao` para a pasta local do seu repositório `wdd131`, execute `git add .`, `git commit -m "Corrige estrutura da pagina inicial"` e `git push origin main`.
5. Em Settings > Pages: Deploy from a branch > main > /(root).
6. Abra https://lirionorng-hash.github.io/wdd131/ e rode novamente a auditoria oficial.

Nota: O HTML usa `lang=pt-BR` porque a página está em português; os padrões gerais do curso exemplificam `en-US`. Confira com seu avaliador se a exigência é literal.
Nota: O relatório anterior registrou erro no carregamento dos recursos do GitHub; isso não permite inferir falhas no CSS local.
